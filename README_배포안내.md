# WEBON 웹온 · 웹사이트 납품 패키지

이 파일들은 별도의 프레임워크 빌드 없이 정적 웹 호스팅에 업로드할 수 있는 **배포용 웹사이트 소스**입니다. 이전의 단일 HTML 시안과 달리 페이지·스타일·기능·설정 파일이 분리되어 있습니다.

## 구성

- `index.html` — 브랜드 메인 / 중앙 정렬 대형 타이틀 / 반응형 기기 미리보기
- `services.html` — 홈페이지 제작 서비스
- `guarantee.html` — 5년 매출 0원 전액환불 보장 제도 및 주요 기준
- `contact.html` — 문의 작성 / 이메일 앱 열기 / 내용 복사 / 카카오톡 안내
- `assets/css/style.css` — 전체 반응형 디자인
- `assets/js/main.js` — 모바일 메뉴, 상담 채널 연결, 문의내용 복사/이메일 앱 연동
- `assets/js/config.js` — 운영 이메일·카카오톡 채널 설정
- `assets/img/` — 로고 및 공유이미지

## 배포 전 반드시 할 일

1. `assets/js/config.js`를 열어 **실제 카카오톡 상담 링크**와 **실제 수신 이메일**을 입력하세요. 현재 비어 있으며, 아무 주소나 임의로 연결하지 않았습니다.
2. `index.html`에 있는 **‘업계 최초’** 문구는 객관적인 근거를 확인한 뒤 공개하세요. 확인되지 않으면 `5년 환불보장형 홈페이지!` 등으로 교체해야 합니다. 검증 전 공개를 피하도록 시안에는 안내 문구를 표시했습니다.
3. **5년 환불보장 약관을 법률 검토 후 확정**하세요. 환불 대상 금액, 매출 인정 기준, 사업주의 홍보 활동 입증, 사업 종료/폐업 및 분쟁시 처리, 운영 중단 시의 정산 등이 확정되어야 합니다. 현재 안내는 서비스 구상 단계의 정책 요약이지 서명 가능한 최종 약관이 아닙니다.
4. 실제 예약 시스템 / 회원 관리 / 결제 / 광고 수익모델은 **고객에게 납품하는 홈페이지에 붙이는 기능**이지 이 웹온 회사 소개 사이트의 백엔드가 아닙니다. 데모 기기 화면은 이미지형 시각 예시입니다.
5. 사이트에서 방문자 정보를 직접 수집·저장하는 서버는 없습니다. **현재 제작문의는 이메일 앱(`mailto:`) 연동 또는 복사 방식**으로만 작동하고 자동 접수되지 않습니다. 서버 자동 접수/관리자 대시보드/실제 고객 개인정보 저장 기능은 추가 개발 및 개인정보처리방침이 필요합니다.
6. 정식 게시 시 운영자의 사업자 정보, 연락처, 상호, 개인정보처리방침(개인정보 실제 처리 방식에 맞게), 정식 이용약관 등 필요한 내용을 채워야 합니다. 실재하지 않는 전화번호/주소/가짜 고객 후기는 기입하지 않았습니다.
7. 도메인 연결 후 절대 URL을 사용한 canonical/OG URL·사이트맵 및 검색엔진 인증을 설정하는 것을 권장합니다.

## 실행 방법

- 바로 보기: `index.html` 더블클릭.
- 로컬 서버 테스트: 폴더 안에서 `python -m http.server 8000` 실행 후 `http://localhost:8000` 접속.
- 배포: GitHub Pages, Netlify, Cloudflare Pages, 일반 웹호스팅 등의 공개 디렉터리 루트에 폴더 안 파일 전체 업로드. (ZIP 파일 자체가 아니라 압축 해제된 내용)

## 테스트 체크리스트

- [ ] PC / 태블릿 / 모바일 레이아웃 확인
- [ ] 네비게이션 / 모바일 햄버거 메뉴
- [ ] 상담 버튼 및 외부 채널 링크
- [ ] 필수 입력값 미입력 시 폼 검증
- [ ] 이메일 프로그램 전송 버튼 동작 (전송은 사용자가 최종 완료)
- [ ] 문의 내용 복사 버튼
- [ ] 보장 조건 및 법률 검토
- [ ] 실제 사업자 정보 및 채널 설정

참고: 이 패키지는 **실제 배포가 가능한 정적 기업 웹사이트**입니다. 100% 운영 완료를 위해서는 운영 채널과 법무·사업자 정보를 확정하고, 자동 문의 수집이 필요하다면 서버/폼 서비스 연동이 별도로 필요합니다.
